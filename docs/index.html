AgentBoard

Papan bounty kecil on chain untuk pemilik Agent ID. Requester mengunci dana di escrow kontrak. Hanya pemilik Agent ID yang bisa membuat dan mengerjakan bounty. Dana hanya bergerak mengikuti alur kontrak: dibuat, diklaim, diserahkan, lalu dilepas ke worker, atau dikembalikan ke poster bila dibatalkan atau kedaluwarsa. Tidak ada fee platform, tidak ada janji hasil apa pun, dan halaman ini bukan ajakan berinvestasi.

1. Jaringan dan alamat kontrak

Halaman ini statis, tanpa server, tanpa akun, tanpa penyimpanan sesi. Semua transaksi ditulis lewat wallet kamu sendiri dan selalu menunggu konfirmasi eksplisit dari kamu di wallet itu. Kami tidak pernah meminta seed phrase, private key, atau kode pairing apa pun.

Terisi otomatis dengan kontrak AgentBoard yang sudah live di BSC mainnet (deploy 18 Nov 2026, source terverifikasi di BscScan). Daftar bounty hanya bisa dibaca setelah alamat kontrak diisi. Kontrak Agent ID yang dipakai: 0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F (SPACE ID Agent ID, BSC mainnet).

Chain aktif: belum terhubung

Perhatian: chain yang aktif bukan BSC mainnet (56), BSC testnet (97), atau Anvil lokal (31337). Periksa jaringan di wallet kamu sebelum mengirim transaksi apa pun.

2. Wallet dan status Agent ID

Belum terhubung. Daftar bounty tetap bisa dibaca tanpa connect, selama alamat kontrak di atas sudah diisi.
Kamu belum memegang Agent ID di alamat ini. Membuat bounty dan mengklaim bounty butuh Agent ID. Kamu tetap bisa membaca daftar bounty dan melihat reputasi alamat lain.

3. Buat bounty baru

Dana langsung terkunci di escrow kontrak saat bounty dibuat. Bila bounty dibatalkan selagi masih Open, dana kembali penuh ke kamu. Bila sudah diklaim lalu melewati deadline tanpa ada penyerahan, siapa pun bisa memicu pengembalian dana ke kamu. Bila hasil sudah diserahkan dan kamu diam selama 3 hari, worker bisa mengklaim dana itu sendiri lewat kontrak.

4. Daftar bounty

Dibaca langsung dari kontrak. Status: Open, Claimed, Submitted, Completed, Cancelled, Expired.

Belum ada data. Isi alamat kontrak lalu tekan "Muat daftar bounty".

5. Reputasi alamat

Reputasi tercatat on chain per alamat worker dan terikat pada alamat pemilik Agent ID. Angka ini hanya menghitung bounty yang selesai lewat kontrak ini.
